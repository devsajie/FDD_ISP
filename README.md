# Nepal Space Telecom

A sleek static landing page for a Nepal-based satellite broadband service, designed to showcase LEO internet plans, coverage, technology advantages, and order flow for Kathmandu users.

## Overview

This project is a front-end marketing website built with plain HTML, CSS, and JavaScript. It presents:

- A premium hero section
- Pricing and plan cards
- LEO vs GEO technology comparison
- Feature highlights for Nepal weather conditions
- FAQ accordion
- Coverage modal and order form interaction
- Animated stats section

## Project Structure

- `index.html` — page structure and content
- `style.css` — visual styling and responsive layout
- `script.js` — interactive behavior such as counters, modal logic, form validation, and FAQ toggles
